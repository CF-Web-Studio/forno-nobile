# Forno Nobile — Showcase CF Web Studio

Três demonstrações independentes da mesma marca fictícia (Forno Nobile, pizzaria napolitana), evidenciando a diferença entre os níveis **Essencial**, **Profissional** e **Premium** de presença digital.

- `/essencial/` — landing page simples, moderna e responsiva. HTML/CSS/JS puro.
- `/profissional/` — site com direção visual mais forte, storytelling, parallax leve, cardápio completo, FAQ. HTML/CSS/JS puro.
- `/premium/` — experiência cinematográfica com Three.js: pizza 3D procedural, exploded view, blueprint técnico, seleção de ingredientes, partículas e câmera guiada por scroll.

Publicado via GitHub Pages a partir da branch `main` (`.github/workflows/deploy.yml`).

Projeto conceitual — demonstração comercial da CF Web Studio. Nenhum cliente, prêmio ou depoimento é real.
